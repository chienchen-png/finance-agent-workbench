## 第一章 快速上手

### 1.1 软件是什么
Finance Agent Workbench 是面向财务人员的**智能工作台**。它能帮你：

- **核对数据**：两份 Excel 金额比对、找差异、确认后自动修正
- **查询与分析**：对 Excel 做统计、建模、图表、趋势分析
- **生成报告**：一键产出可导出 Word 的分析报告

软件**离线可运行**（数据保存在本机），需要" AI 智能功能"时需提前配好模型。

### 1.2 如何启动
> **方式一（推荐）**：双击项目目录下的 **`Finance Agent.exe`**。
> **方式二**：在项目目录命令行执行 `python app.py`。

启动后自动打开浏览器进入 **工作台总览** 首页。

【截图占位：启动后浏览器首页】

### 1.3 首次使用前必做：配置 AI 模型
> ⚠️ **重要**：软件本身能离线运行，但 **"AI 问答 / 智能分析 / 报告撰写"需要先配好模型**（第四章）。
> 如不配置，部分"AI 自动"功能会降级为**确定性功能**（仍可用，仅少了 AI 归因/建议）。

## 第四章 AI 功能配置

> **用途**：告诉软件"用哪个 AI 模型、怎么调"。**不配置 = 用不了 AI 功能**。

【截图占位：AI 功能配置页（模型配置 Tab）】

### 4.1 三个 Tab
| Tab | 作用 | 是否必配 |
|---|---|---|
| **模型配置** | 管理"供应商 + 模型" | **必配** |
| **智能体配置** | 查看智能体执行模式/参数 | 只读 |
| **Skill 配置** | 查看已加载技能模块 | 只读 |

### 4.2 模型配置：添加供应商（首次必做）
1. 右上角点 **＋**（新增供应商）
2. 弹窗填写：
   - **名称**：任意（如"内网模型"）
   - **API 地址**：模型服务网址（如 `https://api.deepseek.com` 或内网地址）
   - **API Key**：密钥（password 输入框）
   - **描述（可选）**：备注
3. 点 **测试连接** 确认能通
4. 点 **保存**

【截图占位：新建/编辑供应商弹窗】

> ⚠️ **易错点**：**API 地址**填的是网址，**API Key**填的是密钥，两者**不要混填**。

### 4.3 供应商下的模型
供应商可挂多个**模型**（如 deepseek-v4-flash、glm、qwen）。每张模型卡右侧有图标：

| 图标 | 作用 |
|---|---|
| ⭐ | 设为默认模型 |
| ✏️ | 编辑模型（名称/图标/类型/能力/上下文窗口） |
| 🗑 | 删除模型 |

**添加模型**：供应商卡片内点"**＋ 添加模型**"，填名称 → 保存。

**模型字段**：
- **类型**：`chat`（对话）/ `embedding`（嵌入）/ `reranker`（排序）等
- **能力**：对话、工具、视觉（用逗号分隔）
- **上下文窗口**：一次处理多少文字（如 200000）
- **设为默认**：AI 默认使用该模型

### 4.4 智能体配置 / Skill 配置（只读）
- **智能体配置**：查看智能体的**执行模式、最大迭代、计划审批、上下文预算**等
- **Skill 配置**：查看已加载的技能（如财务建模 Skill）及其步骤
> 这两页主要给实施人员看，日常不用改动。

## 第五章 对话工作台

> **用途**：自由地与 AI 对话，让它读你的 Excel、做分析、修数据——**长尾自由任务**的入口。

### 5.1 进入
左侧"项目列表"点一个项目名，即进入该项目工作台。

【截图占位：对话工作台（含空状态建议）】

### 5.2 界面组成
| 区域 | 说明 |
|---|---|
| **对话主区** | 你与 AI 的消息流（居中滚动） |
| **输入区工具行** | 模型选择器 / 工作模式 / 项目目录 / 数据 |
| **输入框** | 输入任务，Enter 发送、Shift+Enter 换行 |

**空状态**会显示：
- "✨ 尝试这样开始"建议提示词（点击填充输入框）
- "💡 我能做什么"能力清单（项目文件/Excel分析/差异核对/图表生成/财务建模/写回）

### 5.3 输入区工具行
| 按钮 | 作用 |
|---|---|
| **模型选择器** | 切换 AI 模型（下拉选择） |
| **工作模式** | `人工审批`（改数据前问你）/ `全自动`（直接执行） |
| **项目目录** | 打开右侧文件目录抽屉 |
| **数据** | 打开项目数据库 |

**工作模式（重要）**：
- **人工审批**：AI 要写回数据前会**先弹出确认**，你没有同意不会改 Excel
- **全自动**：AI 直接执行写入（适合信任场景）

### 5.4 项目目录抽屉（右侧）
点工具行"**项目目录**"打开，可管理该项目的全部文件。

【截图占位：项目目录抽屉（文件树）】

**顶部工具按钮**：
| 图标 | 功能 |
|---|---|
| ✚ 新建 | 新建文件 / 新建文件夹 |
| ⬆ 上传 | 上传文件 / 上传文件夹 |
| ↻ | 刷新目录 |
| ✕ | 关闭抽屉 |

**双击文件**：
- **Excel / Word / PPT**：直接调本机程序打开
- **PDF / 图片 / 文字 / Markdown**：新标签页预览

**右键文件**（更多操作）：
- **打开** / **添加到项目数据库** / **引用**（插入 @file: 到输入框）
- **重命名** / **复制** / **剪切** / **粘贴** / **删除**
- 目录上：**新建文件** / **新建文件夹** / **上传文件到此**

> ⚠️ **删除会删除系统磁盘上的真实文件**，不可恢复，请谨慎。

### 5.5 怎么做一次分析
1. 左侧选好项目（第五章入口）
2. 点"**项目目录**"找到要分析的 Excel
3. 在输入框描述需求（可按 **@** 引用文件），如："帮我核对这份 Excel 的金额"
4. 发送 → AI 读取、分析、展示结果
5. 需要改数据时 → 依据工作模式确认（人工审批会弹窗）

## 第六章 数据核对与校验（集成应用一）

> **用途**：把两份 Excel（如"依据表"与"分表"）做**金额核对**，找出差异、审计确认、自动修正。适合**做账、对账**场景。

### 6.1 进入
左侧"集成应用"→ **数据核对与校验**。

【截图占位：数据核对与校验 首页（6步导航 + 模型选择 + AI 专用卡）】

### 6.2 顶部共享栏
- **标题**：数据核对与校验
- **副标题**：按向导配置两表核对，AI 自动完成匹配、分级、归因与写回
- **模型选择器**：右上角（选择本次 AI 基于哪个模型）
- **应用专用 AI 卡**：可点击展开，查看"AI 职责与约束"

### 6.3 核心：六步向导（左侧竖排，可回退）
| 步骤 | 你要做什么 |
|---|---|
| **① 数据文件** | 选依据表（基准）+ 分表（待核对） |
| **② 匹配键** | 设两表共有的唯一标识列（一级必填，可加二级/三级） |
| **③ 核对变量** | 选要核对金额的列（分表金额列 + 依据表金额列），带 AI 推荐 |
| **④ 容差&策略** | 设容差（元）+ 匹配不上如何处理 + 是否自动写回 A 类 |
| **⑤ 校验** | 点"开始校验"，出结果（核对报告 + 待审计清单） |
| **⑥ 修改** | 勾选差异 → 确认写回 → 输出文件 |

### 6.4 步骤①：数据文件
- 标题"选择数据文件"，两个下拉：**依据表（基准）**、**分表（待核对）**
- 右上角"**项目数据库**"按钮：上传/删除/刷新 Excel 数据

#### 项目数据库抽屉（重要）
点"项目数据库"从右侧滑出，功能：
- **上传 Excel**：支持多文件
- **表头锚定确认**：上传时确认**"数据从第几行开始"**（表头行）
- **索引查看 / 删除 / 刷新**

【截图占位：项目数据库抽屉 + 表头确认弹窗】

### 6.5 步骤④：容差 & 策略
| 配置项 | 说明 |
|---|---|
| **容差（元）** | 金额相差多少内算"匹配"（快捷值 0/0.01/0.1/1/5） |
| **匹配不上怎么办** | A. 列表清单供人工复核 / B. 按（人员+客户）降级 / C. 全部标记无法匹配 / D. 自定义 |
| **A 类差异自动写回** | 开关（开启则 A 类差异确认后自动修正） |

### 6.6 步骤⑤：校验结果页
三个区块：
1. **核对报告**：AI 生成的核对结果报告（Markdown）
2. **待审计清单**：未匹配/有疑问的记录，逐个处理
3. **历史运行**：之前的核对记录（可查看/一键重跑）

#### 待审计清单处理
- 上方有分组 tab：全部 / 总表独有 / 分表独有 / 一对多模糊
- 每条记录：类型、关键值（匹配键）、原因，右侧下拉选"**我的决策**"（补录/忽略/确认对应关系）
- 底部"**提交决策 → 下一轮核对**"，可多轮审计直至清零
- 处理完毕提示"未匹配记录已全部处理完毕，可以进入确认修改"

### 6.7 步骤⑥：确认修改（写回）
进入后显示**差异明细表**（每页 200 条）：
- 每行：勾选框、级别（OK/A1 漏填/A2 误差/B 待确认/C 无法匹配）、合同编号、金额、差异、AI 归因、AI 建议
- **A1/A2 默认勾选**；B 需人工勾选；C 不可勾选（不可修正）
- 顶部：**全选/取消**、分页（上一页/下一页）

**写回**：
- 点"**▶ 确认修改（N 条）**" → 自动把勾选的差异**精确写回原 Excel**（只改勾选的单元格，其它格式/公式 100% 保留）
- 写回前**原文件自动备份**（.bak），可恢复
- 完成后出现"**输出文件**"：每条文件可**打开 / 下载导出**

【截图占位：差异明细表 + 确认写回】

> **历史运行**可"**以此次配置重新核对**"一键重跑，省去重设参数。

## 第七章 财务建模与分析（集成应用二）

> **用途**：把多份 Excel 合并，做**财务建模、图表、趋势分析**，并自动生成**可导出 Word 的分析报告**。适合不懂建模但想要分析结论的业务人员。

### 7.1 进入
左侧"集成应用"→ **财务建模与分析**。

【截图占位：财务建模与分析 首页（4步导航 + 模型选择 + AI 专用卡）】

### 7.2 顶部共享栏
- **标题**：财务建模与分析
- **副标题**：按流程引导从数据到报告，AI 完成建模、图表与撰写
- 模型选择器 + 应用专用 AI 卡（同应用一）

### 7.3 核心：四步向导 + 历史记录
左侧竖排：**①诉求与数据 → ②宏观建模与映射 → ③图表风格 → ④AI 撰写报告**，分隔线下方是**历史记录**（第 5 项）。

### 7.4 步骤①：诉求与数据
- 标题"你的分析目标是什么？"
- **诉求输入框**：一句话描述目标（如"分析 2025 年各月回款提成的季度趋势与波动原因"）
- **数据文件**（项目数据库 · 已导入 N 个）：勾选参与分析的 Excel（**可多选，自动合并建模**）
- "**管理数据（上传/删除）**"按钮：打开项目数据库抽屉上传新 Excel
- 点"**下一步**"进入建模

【截图占位：诉求与数据（输入目标 + 勾选文件）】

### 7.5 步骤②：宏观建模与映射（含两个子 tab）
```
① 建模方向      ② 变量映射（N 模型）
```
- **① 建模方向**：AI 根据目标推荐分析模型（默认勾选，可取消）；下方"模型库"（A-G 分类，32 个）可手动补充；选至少 1 个才能下一步
- **② 变量映射**：自动把模型所需变量对应到你的列（低置信可手动改下拉）；支持派生公式、数据预处理

【截图占位：建模方向（AI 推荐模型卡）】

### 7.6 步骤③：图表风格
- **复杂度**（简单/中等/复杂）+ **偏好类型**（趋势/对比/占比等，多选）+ **配色**（蓝橙/蓝绿等）
- **AI 推荐图表**（默认加入清单，可移除）
- **图表库**可手动勾选补充
- 确认清单（N 张，可调变体/配色/顺序）
- 点"**下一步（AI 撰写报告）**"

【截图占位：图表风格 + AI 推荐图表】

### 7.7 步骤④：AI 撰写报告（含两个子 tab）
```
① 确定性执行      ② AI 撰写报告
```
- **① 确定性执行**：自动并行计算模型 → 显示"模型计算结果"（成功/失败）+"图表（N 张）"（所见即所得）→ 底部"**下一步生成**"
- **② AI 撰写报告**：点击后自动生成报告（进度条"AI 正在撰写报告…"）→ 完成后**内嵌预览**

**【报告预览区】（重要）**
- 标题"**报告预览**" + 徽章"**AI 报告**"（或"确定性降级"）
- 报告**直接预览**，可：
  - **编辑**：直接改文字
  - **保存**
  - **导出 Word / PDF**（内置功能，含图表、三线表排版）

【截图占位：报告预览（内嵌编辑器 + 图表）】

### 7.8 历史记录（步骤导航最下方）
点"**历史记录**"进入独立页：
- 显示所有已生成分析报告：**文件名 + 生成时间 + 分析诉求**
- 每条操作：**打开**（新标签页预览原报告）/ **删除**
- 顶部"**刷新**"按钮
- 空态："暂无历史报告"

【截图占位：历史记录页】

## 第八章 常见问题与提示

1. **提示"AI 功能未配置/模型不可用"** → 到第四章配好模型供应商+模型。
2. **Excel 传上去后看不到数据** → 上传时注意**表头行确认**（数据从第几行开始）。
3. **报告里图表"裂图"** → 属于预览旧缓存，**Ctrl+F5 刷新**。
4. **导出 Word 图片看不到** → 需服务端已装 cairosvg（离线包已含）+ 重启服务。
5. **想换 AI 模型** → 对话工作台底部 / 应用页面的模型选择器切换。
6. **端口被占用** → `Finance Agent.exe` 自动选 8080-8085 空闲端口。
7. **数据安全** → 数据保存在本机 `data/`，离线运行不外传。
8. **写回会覆盖原文件吗？** → 不会直接覆盖，**先自动备份 .bak**，原格式/公式 100% 保留。
9. **"人工审批"和"全自动"区别** → 人工审批：写回前弹窗确认；全自动：直接执行。

## 附录 B 词汇表

| 术语 | 通俗解释 |
|---|---|
| **项目** | 一次工作任务的容器，装文件、对话、数据库。 |
| **模型 / 供应商** | 供应商=提供 AI 服务的地方（如 Deepseek、内网模型）；模型=里面的具体 AI 能力（如 deepseek-v4-flash）。 |
| **数据平面** | 软件把 Excel 转成内部数据库表（`data_*`），AI 在这上面分析，不直接改 Excel 源文件。 |
| **索引** | 数据表的结构信息（有哪些表、列、类型、样例）。 |
| **匹配键** | 两表共有的"唯一标识"列，用来把两边数据对上（如合同号）。 |
| **容差** | 金额相差多少以内算"匹配上了"（元）。 |
| **写回** | 把核对/修正结果写回原 Excel。写回前会**自动备份 .bak**。 |
| **人工审批 / 全自动** | 写回数据前，AI 是否要征求你同意。 |
| **隐藏项目** | 集成应用背后自动创建的项目（`__app_*`），不用你管，只管用应用。 |
| **AI 报告 / 确定性降级** | 能连上 AI 时是"AI 报告"；连不上时软件用内置规则生成"确定性"报告（仍可用）。 |

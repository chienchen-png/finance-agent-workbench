- [ ] **无用 import**：本文件未使用的导入立即删除
- [ ] **空白变量**：定义后从未被读取的变量（用 linter 检测 `F841`）

- [ ] **重复常量**：同一魔法数字多处硬编码 → 提升为模块常量
- [ ] **未使用参数**：函数签名中从未使用的参数 → 删除或下划线
- [ ] **前端冗余挂载**：`window.xxx` 定义后无人消费 → 删除
- [ ] **兼容残留**：旧引擎废弃函数（如七阶段状态机的遗留）标注 `DEPRECATED` 并规划删除

### 3.13c `tools/finmod_merge.py`（2026-08-23 新增，R1 多文件合并引擎）

**背景**：R1 多文件支持——把「变量映射/执行只吃单一 file_name」升级为「多文件（多表）统一建模」。用户可同时导入多张表（如销售表 + 成本表），引擎按列相似度自动合并成统一 DataFrame 喂给模型。**不改变单文件路径**（file_names 长度 1 时直通，与旧行为一致）。

| `_looks_period(name, typ)` | 期间列判断 | 日期类型 or 列名含时间关键词 |
